# BezotCorp Studio

A self-hosted ecosystem for AI agents, automation systems, developer tooling, and future AI-native applications.

BezotCorp Studio is built around a simple idea: developers should be free to choose their models, providers, infrastructures, and workflows without being locked into a single vendor, platform, or architecture.

The project aims to provide a unified environment where multiple AI systems, coding agents, automation workflows, and future AI-powered tools can coexist and work together.

---

## Vision

Artificial intelligence is evolving rapidly, but many ecosystems remain tied to a single provider, a single model family, or a single deployment strategy.

BezotCorp Studio takes a different approach.

Our objective is to build an open and extensible ecosystem capable of integrating:

- Multiple AI models
- Multiple providers
- Multiple agent systems
- Multiple deployment strategies
- Multiple orchestration approaches

Local-first remains a core principle, while remote and cloud-based infrastructures may be supported whenever they provide additional value.

The goal is not to build around a single LLM.

The goal is to build around freedom of choice.

---

## Philosophy

### Freedom of Model

Users should be able to choose the models that best fit their needs.

### Freedom of Provider

Users should not be locked into a single company or API.

### Freedom of Infrastructure

AI systems should be able to run locally, remotely, or in hybrid environments.

### Freedom of Evolution

The ecosystem should remain adaptable as AI technologies evolve.

---

## Components

### Agent Studio

The first major component of the ecosystem.

Agent Studio provides a unified interface for interacting with AI agents, automation systems, and multiple backend providers.

It serves as the operational control center of the BezotCorp Studio ecosystem.

Additional components may be introduced in the future as the ecosystem expands.

---

## Genesis

The creation of BezotCorp Studio began with a simple observation:

building an entire AI-agent ecosystem completely from scratch would require rebuilding many years of work that already existed elsewhere.

During research into existing agent platforms, orchestration systems, and AI development environments, multiple solutions were explored and evaluated.

Through discussions and analysis performed with the assistance of ChatGPT 5.5, attention was eventually drawn toward the OpenHands ecosystem and, later, to Agent Canvas.

Rather than reinventing every component from the ground up, Agent Canvas provided a strong technical foundation from which a broader vision could emerge.

This decision allowed development efforts to focus on new ideas, future architecture evolution, ecosystem design, and long-term innovation.

The result of that journey became BezotCorp Studio.

## Project Origin

BezotCorp Studio was initially created from the OpenHands Agent Canvas source tree at revision:

`v1.0.0-alpha.10-180-g421b62b7`

Original project:
<https://github.com/OpenHands/agent-canvas>

The project has since been rebranded and continues development under the BezotCorp roadmap, release cycle, architecture decisions, and product vision.

While compatibility with technologies inherited from OpenHands Agent Canvas may be maintained where appropriate, BezotCorp Studio is developed independently and may diverge significantly over time.
